# TunaTrack Roadmap

This roadmap outlines the next phases for TunaTrack as the product moves from internal pilot work to a broader logistics tracking platform.

## Phase 1: Foundation and operations

- Finalize the core company, office, vehicle, and driver management flows
- Improve admin onboarding and access controls
- Validate bulk import workflows for users and fleet records
- Clean up data validation and audit reporting

## Phase 2: Parcel tracking experience

- Build the end-to-end parcel lifecycle: created, assigned, in transit, delivered, and exception states
- Add customer-facing tracking pages with shipment status visibility
- Implement a status history timeline for parcel events
- Improve route and hub assignment logic

## Phase 3: Notifications and communication

- Add email and SMS notifications for key customer events
- Support automated status reminders and delivery confirmations
- Expand support for operational alerts and exception handling

## Phase 4: Reporting and dashboards

- Add delivery analytics, route performance, and fleet utilization dashboards
- Provide summary views for managers and leadership
- Track service-level metrics and issue trends

## Phase 5: Scale and launch readiness

- Harden security, permissions, and audit controls
- Improve deployment configuration for staging and production
- Finalize support workflows, documentation, and onboarding guides
- Prepare the pilot rollout and customer adoption plan

## Current focus

The current development work is centered on the admin management layer, logistics data setup, and delivery-ready tracking workflows.
